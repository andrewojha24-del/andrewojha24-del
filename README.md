## How this portfolio is built

Every project follows the same standard: a working configuration, script, or assessment, screenshots documenting each stage, and an honest README that includes what actually broke or had to be revised along the way, not just the parts that worked on the first try. In the IAM portfolio, several projects hit and resolved real, undocumented issues, including a Delegated versus Application permissions misconfiguration, a Domain Controller's restricted time authority behaviour blocking sign in, and a SCIM provisioning failure traced back to a missing source attribute — all covered in the Troubleshooting Casebook. In the GRC portfolio, the equivalent honesty shows up in scoring revisions: maturity levels and control statuses that were walked back from an initial generous rating once enforcement and evidence sufficiency, not just presence, were applied as the real standard.
