## How this portfolio is built

Every project follows the same standard: a working configuration or script, screenshots documenting each stage, and an honest README that includes what actually broke along the way, not just the parts that worked on the first try. Several projects hit and resolved real, undocumented issues along the way, including a Delegated versus Application permissions misconfiguration, a Domain Controller's restricted time authority behaviour blocking sign in, and a SCIM provisioning failure traced back to a missing source attribute. Those are covered in detail in the individual project READMEs and consolidated in the Troubleshooting Casebook above.
